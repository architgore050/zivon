Landing concepts v2 · 16 Nov 2026 · base Field Notes §1–§9

Three ads.
Three readers.

One product, three honest entrances. Pick the one that should own /; the other two become campaign pages. Same promise, different argument, composition and artifact.

This is a design exploration. No product code, no backend, no microphone, no analytics. All CTAs are local anchors; product routes are not wired here.

The rule this time

  1. 01The brand frame is base Field Notes: flat paper, ink, Bricolage, Courier, square corners, one pen mark.
  2. 02No §10 in the landing chrome — no ruled grid, no tape, no Caveat, no language bar, no voice dock.
  3. 03The one exception is the framed real-page screenshot on concept C: a product artifact can contain §10 content.
  4. 04One promise and one action per page; the action keeps the same words everywhere.

Choose a reader, not a colour

Three different arguments.

Each concept names one entrant, one awareness stage, one honest emotion and one action. The headlines and sections below the fold change with the reader; the product does not.

The verdict

What I need you to decide.

Not “which one is prettier”. These are positioning and proof decisions; the winner gets implemented in this session.

  1. Which reader owns /? My recommendation: A for /, B for a board-practice campaign URL, C for /about or a launch-log page. Agree, or reassign.
  2. If A owns /: mechanism or tension? A’s chosen headline is the mechanism (“Ask the page…”); the tension variant is “You read it. You nodded. You still can’t do the numerical.” Which argues better to a referral student?
  3. If B owns the exam campaign: outcome or objection? Chosen: “Know what you actually know.” The objection variant is “A score is not a map.” Which is the stronger first screen?
  4. Coverage posture. B uses launch-state coverage (Class 9–10 tests/practice); A uses the current Class 9 state; C uses the current six-page state. Should the landing promise the launch catalogue, or ship the current catalogue and let it grow? This changes the copy and the claim ledger.
  5. Artifacts. A’s transcript and B’s test result are labelled samples. Do you accept samples for this verdict, or should implementation wait for a real consented recording and a live test capture?
  6. CTA destination. Should “Open a chapter” go to the catalogue or straight to the strongest live chapter? My recommendation: strongest live chapter, no account gate.
  7. The “I” voice. C is written in the founder’s voice. If C is not /about, is that voice allowed on a public hook page?

Scope guard

Base brand, not lesson cosplay.

All three pages are flat paper with Bricolage/Courier, square corners, one pen annotation and no gradients, stock images, or SaaS cards. The only §10 content is the real lesson screenshot inside concept C’s framed product artifact.

What changed from the rejected shell

  • No ruled-line page background anywhere on the landing page.
  • No taped cards, no lesson language bar, no voice dock, no Caveat in the chrome.
  • No app-shell dashboard; these are ads, each with one action.
  • The lesson page appears only as a framed screenshot on C — the product artifact, not the frame.

How to review

  • Open each at 1280 px and 360 px; check the CTA is visible before scrolling on a 360×640.
  • Run the 5-second test: what is this, who is it for, what can you do, what does it cost?
  • Run the swap test: replace the wordmark with a competitor’s. Which page still works?
  • Read the headings only; they should form the argument.
  • The full briefs, storyboards, copy decks and claim ledgers are on the thinking page.

Read the argument behind the pixels.

Every section, headline, CTA, proof line and objection is in the thinking page — including what is a sample and what must be replaced before launch.
