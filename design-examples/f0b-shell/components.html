Buttons

44 px minimum. Primary is ink; secondary is outline; quiet is a text action; danger is reserved for destructive actions.

Variants

Hover changes fill or weight, never hue alone. Focus is the doctrine's 3 px pen-blue ring.

States

Busy is words + dashed underline, not a spinner. Disabled controls stay readable and never pretend to work.

Fields

Labels above fields; placeholders are examples, not labels. Errors say how to fix the field and are tied with aria-describedby.

Dialog, sheet, toast

A dialog is a blocking decision; a toast is a transient confirmation. One toast at a time, no focus steal.

Dialog

Native <dialog>: focus moves in, Esc closes, focus returns to the trigger.

Sheet

Bottom-aligned on phones, respects safe-area insets, never a second conversation surface.

Toast

role=status, auto-dismisses, the message is never the only copy of something important.

Exam paper

Title, sections, marks and duration at the top; marks sit next to the question; the palette is shape + words.

A blocking decision

This is a native dialog. Focus moves inside, Esc closes it, and focus returns to the button that opened it.

Use a dialog for consent, deletion and submission — not for a passing confirmation.

A bottom sheet

A sheet is for a short, local task: filters, settings, or the voice dock. It respects the safe area and never locks scroll unless it is modal.
