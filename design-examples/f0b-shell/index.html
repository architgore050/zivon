Non-negotiables visible in every screen

If a reviewer finds one of these broken, it is a defect, not a preference.

  • No gradients, glass, blur, drop shadows, tilted cards, stock photos, or corporate icons.
  • No new colour, font, or radius: the tokens are the doctrine's.
  • Every status carries shape and words; colour is never the only signal.
  • 44 px touch targets, visible pen-blue focus, keyboard paths for tabs, dialogs, drawers and menus.
  • No dead links: in-development chapters are not links; a missing asset removes its control.
  • 360 px has no horizontal overflow; the lesson stays readable with JS off.
  • Local fonts only; zero external requests; no analytics, trackers, or third-party hosts.
  • No streaks, leaderboards, ranks, parent access, or guilt copy.

Review checklist

What is deliberately not here

Owned by other workstreams; not redesigned in this bundle.

Auth screens

F2 owns login, signup, verification and onboarding. This bundle shows the app shell's auth-required state only.

Full voice-dock machine

§10.12 is founder-authored and binding. Only the collapsed containment shell and consent gate are shown, so the shell can be judged around them.

Admin cockpit

F10 owns `/admin/*`. The staff surface is dense and separate; it is not a student surface.

Backend and real data

Every number, name, chapter and score is mock data. No API, database, cookies, microphone, or network request exists in this bundle.
