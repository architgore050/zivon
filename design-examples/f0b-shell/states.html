F0B · state kit · review evidence

What the student sees when it fails.

The shared state kit at shell level: loading, empty, panel error, offline, auth-required, quota, mic denied, untranslated and reduced motion. Every plate names the rule; screen-specific copy lands with each workstream.

Jump to the 360 px frames Your OS setting is always respected; the button simulates it for this page.

Loading

[ssr] + [island]

Loading your study log…

Server paints the shell first; islands show a quiet inline status. No full-page spinner, no shimmer under reduced motion.

Empty

[ssr]

No doubts yet

Ask one from a lesson. The tutor keeps the page and block as the anchor.

Open a lesson

Say what is missing, why, and one action. A blank panel is never an empty state.

Panel error

[ssr]
Could not load your SWOT snapshot

The rest of your study log is here. Your progress is safe; the snapshot needs the server.

Back to dashboard

Panel-level errors stay local; one sentence, a retry, and a way back. No stack trace, no raw model text.

Offline

[shell]

You're offline

Cached lessons still read. Voice and saving need a connection; nothing is lost.

Open a cached lesson

Keep the readable content; disable the network action with a reason. Never fake a success.

Auth required

[ssr]

Session ended

Log in to keep your progress

Your device progress is safe. You can keep reading as a guest; practice and tests need an account.

Continue as guest

Private pages redirect with a safe return path; no redirect loop. The auth screen itself is F2 scope.

Quota exhausted

[shell]

Voice is used up for today

30 credits/day · resets 00:00 · reading, sims, typing free.

Voice is off; typed input is open.

0 / 30 credits left · an in-progress turn always finishes.

The ledger line is exact; the mic is disabled with words. Practice, reading and typing keep working.

Permission denied

[island]
MIC OFF

The microphone permission was declined.

You can still read the prompt and the model answer. To try again, allow the microphone in your browser settings and reload.

Back to the lesson

Explain, offer the non-permission path, never re-prompt in a loop. No red toast.

Untranslated

[page]
Hindi is not ready for this block — showing English

Only the net force decides the motion.

English is shown with a visible marker. The rest of the page stays in the selected language; nothing is silently mixed.

A missing translation is a publish failure for a live lesson. This plate shows the honest fallback, not a silent English page.

Reduced motion

[css]

The waveform becomes a static frame; captions appear instantly; no caret, bars, sweep or count-up. Audio is unchanged.

Use the “Reduced motion” button above to simulate the OS setting on this page. The production components respect prefers-reduced-motion.

Consent missing

§10.14

Voice is off

Before the microphone, Zivon explains what is recorded.

Voice becomes text; audio is not kept; Gnani processes the speech; the lesson works without voice. Declining never re-nags and reading, sims and typing stay free.

See the full consent sheet

The gate is per device and founder-authored (§10.14). This bundle does not redesign it; the lesson page shows the sheet.

The 11-state rule, at shell level

A screen-specific matrix is still required per workstream; this is the shared treatment only.
Shared state kit — what changes and what must never happen
StateShell treatmentNever
DefaultThe designed screen; one primary action where the screen has one.Fake progress or a second primary action.
LoadingShell first; skeleton shaped like the content; quiet inline status.Full-page spinner, shimmer under reduced motion.
EmptyExplain what is missing and one next action.Blank panel, fake “0%” data.
PartialRender what exists; label the missing part; no dead link.Stub a chapter that is not published.
ErrorPanel-local sentence + retry + way back.Stack trace, raw model text, silent failure.
OfflineCached content stays; network actions disabled with a reason.Fake save success; blank screen.

UntranslatedEnglish + visible marker; rest of the page stays in locale.Silent mixing; pretending Hindi is ready.

Review note

What is deliberately not in this bundle

Every screen still needs its own 11-state matrix; this page proves the shared kit, not every copy. The voice dock's full state machine is §10.12/F4; auth/onboarding is F2; admin is F10. No backend, network, microphone, localStorage or analytics exists here. The 360 px frames are the real pages at 360 px, not scaled images.
