# Field Notes annotation kit — LOOK REFERENCE ONLY

Reusable hand-drawn annotation shapes extracted from Day 0's **approved** marks layers
(`posts/assets/day-0/A3.xcf`, `A1.xcf`). They define what the pen strokes should look like: weight, wave,
taper, arrow geometry.

**Do not paste these files into assets.** The founder rejected pasted kit marks (1 Nov): pasted PNGs showed
white backgrounds around the strokes on the page ("don't go for cheap tricks, learn to draw this stuff").
All pen marks in post assets are now **drawn natively in GIMP** with the parametric pen-stroke renderer
documented in `skills/content-creation/tools.md` (lesson "Native pen strokes"). Compare every native stroke
against these files for the approved look.

## Files (reference)

| File | Size | Look it defines |
|---|---|---|
| `pen-underline.png` | 797x16 | Hook underline: 5-6px pen-blue stroke, gentle wave, taper at right end |
| `arrow-steep.png` | 58x80 | Steep connector arrow pointing down-left (Day 0 A3 look) |
| `arrow-shallow.png` | 178x26 | Shallow connector arrow pointing left (Day 0 A1 look) |

All shapes are pen-blue `#1F3A9E` on transparent. `*-zoom.png` previews are 3x nearest-neighbor views for
review only.

## Rules (from photo-edit-director)

- At most one annotation on a proof image; annotations decode the proof, never restate the hook.
- Callout text under 7 words, Caveat Bold, pen-blue.
- Underlines extend a few px past both ends of the text they underline; strikethroughs pass through the
  x-height middle of the struck word.
- QC every pen mark: zero near-white pixels in a band around the stroke (a white background means the mark
  was pasted, not drawn — rebuild it natively).
