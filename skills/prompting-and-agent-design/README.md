# Prompting and agent-design skill

One skill: how to prompt current-generation LLMs and design the agentic
systems around them, applied to Zivon's content factory (and, from Phase 2,
the voice tutor prompts). Read `SKILL.md` when writing, reviewing, or
refactoring any agent prompt or agent-graph decision; read
`references/sources-and-evidence.md` when a prompting/guardrail decision is
contested — it dates every rule to its source.

## Layout

- `SKILL.md` — the skill entry point: the control-layer model, current-era
  prompting rules, factory (multi-agent) design rules, the authoring loop, and
  the anti-pattern list.
- `references/sources-and-evidence.md` — dated bibliography behind the rules
  (`[S#]` ids), the founder-thesis mapping, and maintenance rules.

Root `README.md` and `AGENTS.md` point here and stay abstract; this file is
the source of truth for the folder's layout.
