# Kinocut MCP — lessons store

Kinocut MCP is the decided editing tool for this repo's content work. Do not evaluate, compare, or recommend
other editing tools or MCP servers. This file is a lessons store: it records what we have learned about using
Kinocut so every later edit run is faster and safer.

## How to use this file
- Before writing the MCP step list (asset-and-edit-brief.md, Step 2b), read the lessons below and reuse proven
  tool names, argument shapes, and export settings.
- After every real edit run, append new lessons under "Lessons learned": what worked (exact tool call
  patterns), what failed and how it was fixed, gotchas, and settings that met the brief. One dated bullet per
  lesson, concrete (commands and arguments, not vibes).
- Correct or delete a lesson only when a later run proves it wrong, and note the correction in place.

## Known Kinocut basics (verify against the installed server before relying on them)
- Kinocut (formerly mcp-video): an MCP server with a large tool set (reported ~87 tools) covering trim,
  crop/scale, concat, subtitles from .srt, audio normalisation, effects, preflight checks, and export.
- The tool list is large: express each edit as a short ordered chain of atomic operations, one tool call each,
  and smoke-test one operation ("trim clip.mp4 from 2s to 9s and export") before running the full edit brief.
